# Abstraction Lab: One Contract, Three Builds
**Course:** Advanced Programming  
**Language:** Python  

---

## 1. Project Overview
This application demonstrates core Object-Oriented Programming (OOP) concepts—specifically **Abstraction**, **Encapsulation**, and **Polymorphism**—by defining a single abstract contract (`CookingPlan`) and building three concrete implementations (`OvenPlan`, `StovetopPlan`, and `CampingPlan`). A shared caller (`RecipeApp.show_plan`) processes each plan dynamically without inspecting or checking the underlying class type.

---
